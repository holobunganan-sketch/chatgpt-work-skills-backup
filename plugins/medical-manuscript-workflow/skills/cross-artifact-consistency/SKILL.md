# 跨交付物一致性协调

## 坚守核心约束

- 锁定权威源、工作文件、派生物和正式交付物之间的关系。
- 为每项共享事实指定唯一权威来源；记录事实值、语义、单位、口径、时间点和定位证据。
- 先建立变更影响图，再实施修改；沿显式依赖边传导，避免机械全文替换。
- 将授权范围视为硬边界；只读检查可覆盖用户指定范围，写入仅限明确授权对象。
- 从同一内容源生成清洁版与标记版；仅允许标记层、批注层或展示层存在预先声明的差异。
- 记录实际完成的改动及证据；不得用计划、推测或回复声明代替真实修改。
- 采用最小充分修改；保护无关内容、用户已有改动、格式和可继续编辑能力。
- 在来源冲突、版本身份不明或影响路径不确定时停止相关写入，列出阻断点并请求决策。

## 执行工作流

1. **确认任务边界**
   - 识别用户允许读取、分析、修改和发布的对象。
   - 区分内容修改、格式修改、重编号、引用更新、派生版本生成和只读核查。
   - 不把“全局检查”解释为“全局改写”。

2. **登记产物与权威关系**
   - 复制并填写 `assets/artifact-registry.template.json`。
   - 为每个产物记录稳定 ID、路径、角色、版本、派生来源、内容维度和发布集合。
   - 为共享术语、数字、编号、引用和版本声明登记规范项及全部已知出现位置。
   - 运行 `python scripts/validate_artifact_registry.py <registry.json> --strict`。

3. **建立变更记录与影响计划**
   - 复制并填写 `assets/change-record.template.json`。
   - 分开记录请求内容、授权范围、规范项更新、直接改动和实际改动。
   - 运行 `python scripts/build_impact_plan.py <registry.json> <change-record.json> --output <impact-plan.json>`。
   - 审查所有 `requires_authorization` 项；获得授权前不得写入这些对象。

4. **按依赖顺序实施**
   - 先修改权威源，再更新直接派生物，最后更新汇总、索引、回应和发布版本。
   - 按语义与上下文核对每个命中位置；排除同形异义、历史引文和无需同步的引用性内容。
   - 同步术语定义、数字口径、单位、编号、交叉引用、引用来源、图表标签和版本标识。
   - 将每项实际改动写入变更记录，保留定位、改前值、改后值、状态和核验证据。

5. **核验并发布**
   - 重新运行登记表校验和影响计划，确认所有必需动作均已关闭。
   - 比较清洁版与标记版的规范化内容，确认差异仅来自允许的展示层。
   - 核对回应材料、修改说明或发布说明中声称的动作均能指向实际产物证据。
   - 只从允许清单组装正式交付集合；把登记表、影响计划和内部变更记录保留在交付集合之外，除非用户明确要求提交。

## 按需读取资源

- 在执行任何实质性协调前，完整读取 [`references/SPEC.md`](references/SPEC.md)。
- 在判断不同变更类型的传导方式时，读取 [`references/PROPAGATION_RULES.md`](references/PROPAGATION_RULES.md)。
- 在接收或输出跨 Skill、跨代理或跨系统记录时，读取 [`references/INTERCHANGE_CONTRACT.md`](references/INTERCHANGE_CONTRACT.md)；把该协议视为可选接口，不把它设为运行前提。
- 在开发、回归测试或评估边界行为时，读取 [`references/EVALUATION_CASES.md`](references/EVALUATION_CASES.md)。

## 独立运行

- 在没有其他 Skill、既有台账或交换协议时，自行从用户提供的文件和要求建立最小登记表与变更记录。
- 在已有登记表或中立交换记录时先验证再复用；不默认信任旧记录的版本、状态或事实值。
- 使用标准 JSON 作为内部接口；允许其他系统忽略未知扩展字段，但不得改变本 Skill 的强制约束。
- 将领域专有规则作为项目级补充；始终保留本 Skill 的权威源、授权边界、影响图和证据闭环。

## 完成标准

- 权威源与派生关系明确且无循环。
- 每项共享事实拥有唯一规范记录。
- 每项变更拥有可审查的影响计划。
- 每个受影响产物均处于“已验证”“明确无需修改”或“等待授权”状态。
- 清洁版与标记版内容同源。
- 实际改动、正式声明和最终交付物能够相互追溯。
- 未获得授权的文件保持不变。
