# DOCX 执行工作流

## 1. 输入准备

保留唯一源文件。将格式化输出写入新文件；文件名清楚区分原稿与格式化稿。先登记用户和目标期刊是否指定论文结构。两者均未指定时使用默认 IMRAD；存在明确要求时先复制默认配置并修改项目副本，用户对当前任务的要求优先。

## 2. 投稿适格审读

格式化前先明确研究问题、用户指定主张、各章节功能和段落主线。逐句询问：“如果今天投稿，这句话应该出现在这一章节、这一段、这个位置吗？”

重点处理：

- 编辑语言、协作痕迹、过程说明、内部状态和面向作者的操作提示；
- Methods 中的执行后结果；
- Results 中的解释、机制、比较和推论；
- Introduction、Discussion 和 Conclusion 中偏离核心主张的中立综述、冗余和立场稀释；
- 只为展示谨慎而增加的证据边界说明、泛化免责声明和自我保护式保留；
- 原稿已经出现但不具备正式功能的“偶然性”“证据有限”“仍需研究”“仍待验证”等泛化保留；
- 章节间机械重复、段落内部逻辑断裂和位置不当的句子。

执行重写、移动、合并或删除后，从目标期刊编辑、审稿人和专业读者视角通读。用户只授权纯排版或只读检查时保持原文，将语义发现记录在交付目录之外。

保留局限时逐项确认其具体指向研究设计、样本、测量、统计分析或外部适用性，且由研究实际情况支持。将合格局限集中放入目标文种规定的局限段落。无法说明限制来源和影响路径的套话直接删除。

## 3. 格式化

```powershell
python scripts/enforce_docx_format.py 原稿.docx 格式化稿.docx
```

脚本执行：

- 修改 DOCX 内的样式和可见文本运行属性；
- 正文使用宋体/Times New Roman、12 磅、纯黑色、1.5 倍行距；
- 各节默认使用上 2.54 厘米、下 2.54 厘米、左 3.18 厘米、右 3.18 厘米页边距；
- 小标题加粗；
- 表格改为三线表；
- 表题置于紧邻表格上方，图题置于紧邻图片下方；
- 明确识别 P 值列后，将显著项目整行加粗；
- 删除 `titlePg` 设置；
- 比较格式化前后的全部字段代码，Zotero 字段变化时拒绝写出。

用户或目标期刊另有页边距要求时，先在项目配置副本中修改 `page_margins_cm`，再运行格式化和审计脚本。

## 4. 文稿审计

```powershell
python scripts/audit_manuscript.py 格式化稿.docx --stage final
```

需要证明 Zotero 字段未变化时：

```powershell
python scripts/audit_manuscript.py 格式化稿.docx --compare-source 原稿.docx --stage final
```

`--stage draft` 允许尚未插入 Zotero 动态域；`--stage final` 将缺少 Zotero 动态域判定为错误。

默认配置同时检查 Introduction、Methods、Results、Discussion 和 Conclusion 的顺序、段落结构与小标题层级。Introduction 和 Discussion 不得设置二级及以下小标题；Methods 和 Results 可以设置二级小标题，每个小标题下使用一个自然段。脚本同时对 Methods 的执行后结果、Results 的解释性表达和 Conclusion 的重复内容进行启发式审计。语义类警告必须逐项阅读原文后判断。项目采用其他结构时，通过 `--profile 项目配置.json` 载入覆盖规则。

## 5. 保护原则

- 不在唯一源文件上运行覆盖操作。
- 不删除或改写字段代码。
- 不接受 DOCX 打不开、字段计数变化、Zotero 载荷变化或正文丢失。
- 不把动态引文扁平化。
- 不修改页眉页脚和期刊专用栏目；页边距只按当前配置写入。
- 不把实际样本量、实际检索量或其他执行后结果留在 Methods。
- 不把结果解释、机制推断或外部文献比较留在 Results。
- 不把编辑过程、自我保护式保留或无正式用途的证据边界说明留在投稿正文。
- 不以论证优化为由虚构或改变研究事实、数据、统计结果、引文和来源。

## 6. 故障处理

- 字段保护失败：停止，比较源文件与输出文件的 `word/document.xml` 字段。
- 复杂表格被误判：恢复该表格，按目标期刊格式人工设置三线表。
- 题注识别失败：将题注改用 Word Caption 样式或标准 `Table/Figure/表/图` 前缀后重试。
- 文稿包含修订或批注：先制作并核对清洁副本，再格式化。
- 视觉分页异常：保持内容不变，单独调整分页、段前段后和对象锚点。
