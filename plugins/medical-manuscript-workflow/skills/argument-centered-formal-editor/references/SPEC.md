## 1. 规范目标

使用本规范重写和编辑复杂正式文本，使核心问题、段落判断、证据任务、句段承接和最终结论形成连续推理。

把全文质量设为最高编辑目标。保留有效原文，重写妨碍主线的结构。根据来源叙事与本文的契合程度决定处理方式。根据全文收益决定是否调整局部主线。

## 2. 核心术语

- **核心问题**：全文需要回答的中心问题。
- **目标答案**：读者完成全文后应当获得的主要判断。
- **主线**：从核心问题到目标答案所需的最短连续推理。
- **主线节点**：主线中的一项必要判断。
- **段落判断**：一个段落需要读者接受的主要结论。
- **推理缺口**：相邻判断之间尚未建立的必要关系。
- **证据任务**：证据在当前段落中完成的具体论证工作。
- **来源叙事**：来源围绕自身问题组织研究对象、方法、结果和解释的方式。
- **叙事契合度**：来源叙事与本文当前主线节点、段落判断和表达视角的匹配程度。
- **最小可用命题**：来源中能够独立推进本文判断的具体事实、关系、比较或解释。
- **推理桥**：连接既有判断、证据贡献、作者判断和后续节点的内部结构。
- **重编译**：按照段落任务和推理顺序重新组织原句、证据和承接关系。
- **来源主导写作**：正文的组织顺序、叙述主体或语气被来源材料牵引，导致本文主线暂时中断。
- **抽象空话**：缺少明确主体、对象、行为、条件或结果的概括性表达。
- **外部引用对象**：Zotero 或其他引文管理器生成并由其维护的 citation key、动态引文域、编号或映射。
- **受保护引用标识**：编辑过程中保持内容、大小写、结构和数量稳定的外部引用对象。

## 3. 强制规则

### 3.1 主线连续

- 在实质编辑前明确核心问题和目标答案。
- 为每个章节和段落指定对主线的具体贡献。
- 让结论直接回答核心问题。
- 让段间关系来自问题推进、因果、比较、递进、解释、例证或归纳。

### 3.2 证据承担任务

- 为每项进入正文的证据指定可复述任务。
- 让证据服务当前段落判断，并推动后续判断。
- 让引用靠近其对应的具体陈述。
- 根据推理需要排列证据。
- 删除只有主题相关性、材料展示价值或反馈存在感的内容。
- 让承担同一任务的多项来源形成综合判断。
- 把连续的作者主导句列重编译为本文主导的句群。

### 3.3 来源处理服从契合度

- 先判断来源叙事与本文的契合程度。
- 高度契合时保留其有效叙事。
- 部分契合时调整主体、术语、句序和局部关系。
- 局部可用时抽取最小可用命题。
- 无推进作用时舍弃。

### 3.4 承接完成推理

- 让承接句补足推理、完成比较、形成递进、解释原因、归纳共同结论或导向下一节点。
- 用具体主体、谓语和对象承担关系。
- 允许句序、比较结构和谓语选择直接表达关系。
- 连接词只能标记已经存在的关系。

### 3.5 学术表达具体

- 优先写明研究对象、样本、变量、干预、行为、测量、变化方向和结果。
- 用具体动词替代无动作信息的抽象名词组合。
- 使用“机制、路径、维度、框架、价值、意义”等术语时写明其具体指向。
- 删除可以放入任何论文的通用判断。

### 3.6 保持编辑完整性

- 保留事实、数值、引用标识、否定关系、受控术语和用户确认的决定。
- 延续作者已经形成的术语系统和语气。
- 把内部工作记录与正式正文分开。
- 在局部修句无法修复论证时扩大编辑范围。

## 4. 条件规则

### 4.1 局部主线调整

仅在下列任一条件成立时调整主线：

- 证据补足了原文缺失的必要推理；
- 证据使两个节点之间出现更清楚的因果、比较或递进关系；
- 证据揭示当前段落同时承担多个判断；
- 调整能够减少旁支、重复或突兀跳转；
- 调整能够提高全文的流畅度和严谨性。

保持主线不动的情形：

- 证据能够自然进入现有节点；
- 调整只会展示编辑过程；
- 调整增加新的旁支；
- 调整破坏已经建立的段间节奏；
- 调整只为容纳一项材料。

### 4.2 来源叙事保留

保留来源叙事的情形：

- 来源与本文讨论同一问题；
- 来源结果承担本文当前需要的同一任务；
- 来源叙述顺序能够自然接续上下文；
- 来源自身属于当前段落的分析对象。

调整或提取的情形：

- 来源的研究问题与本文不同；
- 来源主体进入正文后造成视角突变；
- 来源方法背景占据过多篇幅；
- 来源结论只能提供其中一项关系；
- 来源原顺序打断本文判断。

### 4.3 编辑保留

保留原句的条件：

- 句子准确、清楚并推动段落判断；
- 句子与前后文在主体、术语和节奏上连续；
- 引用任务可见；
- 保留不会妨碍必要重组。

## 5. 禁止规则

- 禁止按照文献、检索、接收或反馈顺序组织正文。
- 禁止把每篇来源写成独立摘要后统一追加解释。
- 禁止强制改写与本文高度契合的来源叙事。
- 禁止为了体现互动而强制调整主线。
- 禁止用“此外、同时、值得注意的是、具体而言”等提示语掩盖关系缺失。
- 禁止重复“某研究发现……这表明……”结构。
- 禁止用抽象名词代替具体研究对象和变化关系。
- 禁止在改写目标段落中保留或新增证据边界、限制条款和防御性说明。
- 禁止把反馈处理过程、内部人物、待办事项和编辑理由写入正文。
- 禁止凭写作习惯补造事实、数值、来源或引用。
- 禁止为了保留原句而留下断裂主线。
- 禁止为了制造差异而全面改写有效原文。
- 禁止主动检索引文管理器文库、选择或替换文献条目。
- 禁止改写 citation key、域代码或动态引文载荷。
- 禁止把动态引文扁平化为普通文本。
- 禁止主动同步、导入、修改文献库或改变引文样式。

## 6. 输入与输出

### 6.1 最小输入

收集：

- 当前正文；
- 文档目的和受众；
- 核心问题或写作任务；
- 来源材料和引用标识；
- 必须保留的事实、数据和术语；
- 用户明确要求处理的反馈。

缺少目标答案时，从正文提炼候选答案并保持内部使用。缺少来源原文时，只处理用户已经提供的证据内容，不扩写来源细节。

### 6.2 内部工作输出

根据任务规模维护：

- 主线节点；
- 段落判断；
- 来源契合度；
- 证据任务；
- 推理缺口；
- 推理桥；
- 编辑层级；
- 事实、数据、引用和术语保留项。

短文本允许在内部完成。长文、多来源或跨章节任务使用结构化工作图。

### 6.3 正式输出

默认只输出最终正文。用户明确要求时再提供修改说明、主线图、引用任务表或风险记录。

## 7. 标准工作流

### 7.1 恢复全文目标

回答：

1. 全文要解决什么问题？
2. 最终需要读者接受什么？
3. 中间必须建立哪些判断？

### 7.2 建立可修订骨架

用短语或短句记录主线节点。保留调整空间，暂不扩写为完整段落。

### 7.3 建立段落任务

为每段记录：

- 读者进入本段时已经知道什么；
- 本段需要建立什么；
- 本段使用哪些材料；
- 本段结束后读者可以继续判断什么。

### 7.4 处理来源

逐项判断契合度和处理动作。为进入正文的证据指定任务、进入点和后续去向。

### 7.5 决定主线是否调整

比较保持原主线与局部调整后的全文效果。选择判断更连续、语言更自然、结构更紧凑的方案。

### 7.6 构建推理桥

写清上文判断、推理缺口、证据贡献、本文判断和后续节点。把内部结构转化为自然句段。

### 7.7 重编译

先处理段落判断和句序，再处理句法、措辞和格式。允许合并、拆分、移动和重写。

### 7.8 双向审计

从核心问题向结论检查每个节点是否连续。从每项引用返回段落判断，检查其任务和位置。

### 7.9 语言审计

检查主体、术语、抽象程度、时态、语气、句长和节奏。删除无具体指向的概括、机械连接和来源主导表达。

## 8. 编辑层级升级

| 发现的问题 | 最低处理层级 |
|---|---|
| 个别指代或术语不一致 | 单句 |
| 引证句主体突然转为“某研究” | 句群 |
| 证据与段落判断缺少承接 | 句群 |
| 多项证据按来源顺序排列 | 整段 |
| 段落同时承担两个主要判断 | 整段 |
| 现象、文献和结论分散在相邻段落 | 相邻段落 |
| 章节顺序无法回答核心问题 | 章节 |

达到最低层级后继续判断是否已经达标。达标后停止扩大。

## 9. 来源与引用处理

### 9.1 保留信息

保留用户提供的：

- 作者、年份和引用编号；
- 原始数值和统计符号；
- 专有名词和受控术语；
- 明确的比较方向和否定关系；
- 引用与具体陈述的对应位置。

### 9.2 允许处理

允许：

- 改变句子主体，使其延续本文视角；
- 把来源结论改写为本文需要的事实、比较或解释；
- 合并承担相同任务的多项来源；
- 拆分承担不同任务的一项来源；
- 移动证据到更自然的段落；
- 删除对主线没有贡献的材料。

### 9.3 引用任务测试

逐项回答：

1. 它在这里完成什么？
2. 它接续上文哪一判断？
3. 它让本文能够继续说什么？
4. 删除内容后哪一步推理中断？

四项无法获得具体答案时，重新组织或移除。

### 9.4 同任务多来源

两项及以上来源承担相同任务时：

1. 先写本文需要的共同判断；
2. 再写各来源共同提供的事实、措施或关系；
3. 把引用放在对应成分后或合并放置；
4. 删除连续的作者主导句；
5. 保留研究主体仅限于研究差异属于当前判断的情况。

证据内容已经完成推理时，删除同义解释。作者判断需要推动到新的局部结论或下一节点。

避免在证据前提前写完证据将要导出的判断。相邻句共享同一主体、行为和结果，后一句只增加引用标识时，合并两句。段落不得形成“提前判断—引证重复—再次总结”的回环。

### 9.5 引文管理器兼容

正文已经含有 Zotero 或其他引文管理器生成的引文时：

1. 编辑前记录全部受保护引用标识及其数量；
2. 识别每项引文当前支持的最小陈述；
3. 重写时让引文随受支持的陈述共同移动；
4. 保留 citation key、命令参数、动态域和映射的原有结构；
5. 拆分句子时把引文留在其支持内容对应的主张后；
6. 合并句子时保留全部原有引用对象；
7. 编辑后比较引用标识集合与数量；
8. 检查移动后的引文是否产生错误归属。

本技能不负责文库检索、条目选择、新引文插入、文献同步、样式修改和参考文献刷新。完整规则见 [CITATION_MANAGER_COMPATIBILITY.md](CITATION_MANAGER_COMPATIBILITY.md)。

## 10. 语言规则

### 10.1 具体化

优先使用：

- 明确主体；
- 可观察行为；
- 可测量变量；
- 清楚的比较对象；
- 具体变化方向；
- 明确结果。

把“具有重要意义”改写为该发现改变了什么判断、解释了什么结果或支持了什么后续动作。把“形成协同机制”改写为哪些主体通过何种行为共同影响哪个结果。

### 10.2 语气连续

检查引证前后：

- 叙述主体是否保持同一视角；
- 同一对象是否使用同一术语；
- 句子是否突然变成文献摘要口吻；
- 抽象程度是否突然升高；
- 时态和判断语气是否突变；
- 句长是否破坏段落节奏。

### 10.3 禁用转折叙事模板

删除或改写以下结构及其变体：

- “不是……而是……”；
- “并非……而是……”；
- “与其说……不如说……”；
- “不只……还……”；
- “不仅……更……”；
- “表面上……本质上……”；
- “真正关键的……”。

使用直接陈述、并列说明、因果说明或具体事实。

## 11. 冲突优先级

按下列顺序处理冲突：

1. 用户明确要求和正式任务目的；
2. 已确认事实、数据、引用标识和受控术语；
3. 全文核心问题和主线连续性；
4. 段落判断与证据任务；
5. 作者声音和文类惯例；
6. 局部流畅度；
7. 自动扫描结果。

自动扫描不能覆盖人工语义判断。

## 12. 发布门禁

全部满足后完成：

- [ ] 核心问题和目标答案清楚。
- [ ] 主线节点连续，结论直接回应开篇任务。
- [ ] 每段具有一个主要判断。
- [ ] 每项引用承担明确任务。
- [ ] 来源处理方式符合叙事契合度。
- [ ] 主线调整具有可说明的全文收益。
- [ ] 推理桥能够由句义复述。
- [ ] 引证处延续本文主体、术语、语气和节奏。
- [ ] 学术文本优先使用具体对象和关系。
- [ ] 证据顺序服从推理顺序。
- [ ] 编辑层级达到修复需要。
- [ ] 事实、数据、引用标识和受控术语完整。
- [ ] 改写目标段落没有保留或新增证据边界、限制条款或防御性说明。
- [ ] 正文没有反馈痕迹、内部过程和待办内容。
- [ ] 风险扫描已经过人工语义复核。
- [ ] 外部 citation key、域代码、动态引文和映射保持完整。
- [ ] 移动后的引文仍紧邻其所支持的最小陈述。
- [ ] 本技能没有调用文库检索、条目选择、同步或样式更新流程。
