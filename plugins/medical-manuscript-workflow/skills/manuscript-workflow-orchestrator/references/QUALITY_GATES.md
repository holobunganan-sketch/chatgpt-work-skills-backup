# 质量门禁

## Reviewer

- 原文覆盖率为 100%；
- 原文顺序、措辞和来源区间可核对；
- 所有意见具有终局决定；
- 未授权修改为零。

## Response

- 每位 Reviewer 一个独立 DOCX；
- 每项 Comment、Response 和 Location 循环完整；
- 修改声明有最终文件证据；
- 删除说明和无需修改理由完整；
- Location 在最终排版后仍然有效。

## 手稿

- Clean 和 Highlighted 来自同一权威内容；
- 非展示性差异为零；
- 删除内容不残留；
- 新增和改写内容使用黄色高亮或期刊指定标记；
- Zotero 字段、书签、交叉引用、图表、表格和样式完整；
- DOCX 可以打开和继续编辑。

## 跨文件

- 摘要、正文、图表、补充材料、引用、编号和 Response 使用同一事实口径；
- 文内图表与独立图表文件一致；
- 所有受影响对象已验证或明确无需修改。

## 交付

- 目录与允许清单一致；
- 白名单外文件为零；
- 内部过程内容为零；
- 文件可打开，命名和层级符合正式用途；
- 独立审计 Critical 和 Major 问题为零。
