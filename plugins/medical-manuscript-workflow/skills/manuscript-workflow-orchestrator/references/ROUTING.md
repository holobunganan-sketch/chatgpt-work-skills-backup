# 工作流路由

## 路由判定

| 可观察状态 | 选择路线 |
|---|---|
| 只有研究材料、结果、文献和图表 | 新建论文 |
| 已有手稿且没有审稿意见 | 普通修订 |
| 存在编辑或 Reviewer 意见 | 审稿返修 |
| 用户明确限定 Discussion | Discussion 专项 |
| 内容已完成且要求投稿目录 | 投稿交付 |
| 用户要求检查、审计或判断 | 只读审计 |

多个状态同时存在时，以审稿返修为主路线，把格式交付和发布审计作为下游阶段。

## 路线进入条件

### 新建论文

- 研究问题和目标文章类型明确；
- 结果来源可验证；
- 文献来源可定位；
- 图表资产可登记。

### 普通修订

- 原始手稿已经锁定；
- 修改目标和授权范围明确；
- Zotero、书签、域代码和其他受保护元素已经登记。

### 审稿返修

- 每位 Reviewer 的原始意见可完整读取；
- 原始手稿和返修基线已锁定；
- 用户被登记为责任决策者。

### Discussion 专项

- Results、主要图表和研究设计可读取；
- 外部证据与研究证据可以区分。

### 投稿交付

- 正文、图表和补充材料处于候选终稿状态；
- 目标期刊要求或默认格式已经确定。

### 只读审计

- 审计对象和范围明确；
- 任何写回动作均未获授权。

## 路线退出门禁

每个路线只有在其正式产物完成、内部错误清零、用户决定已落实且下游依赖可验证时退出。只读审计以报告发现结束，不修改正式文件。
