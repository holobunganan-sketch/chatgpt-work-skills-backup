# 学术提交核查配置

仅在论文、研究报告或期刊返修任务中读取。本配置增加检查项，不降低通用门禁。

## 审稿意见与回复

- 核对每位审稿人的意见数量、原始顺序和完整原文。
- 检查每条 `Response` 是否回应核心问题、限定条件和接受程度。
- 有正文修改时核对 `Location of revision`；无正文修改时检查位置字段是否应省略。
- 检查扩写后的回复是否保持原有中心意思、行动承诺和立场。
- 检查不同审稿人对同一问题的回复是否一致。

## 手稿与派生版本

- 比较 Clean 与 Highlighted 的可见文字，允许高亮属性存在预期差异。
- 检查摘要、方法、结果、讨论、结论和图表之间的术语、样本量、数值与解释。
- 检查图表按首次出现顺序编号，正文引用有效。
- 检查补充材料编号、标题和正文引用。
- 检查引文仍位于其支持陈述之后，参考文献管理字段未被破坏。
- 检查批注、修订、隐藏文字和内部过程说明。

## 写作与证据边界

- 检查正文是否出现面向审稿人的补丁式解释。
- 检查 Results 是否反复强调因果限制或分析边界。
- 检查 Discussion 中每项文献是否承担比较、支持、机制、意义或边界功能。
- 检查 Conclusion 是否回应研究问题并与结果保持同一证据强度。

## 交付包

- 保留手稿、正式图表、补充材料、回复信和期刊要求文件。
- 将修改报告、中文翻译、检索记录、统计工作文件、核查报告和备份留在交付目录之外，除非期刊明确要求。
