# Medical Specialization

Use this layer on top of the shared research core.

Medical framing should explicitly capture:
- clinical significance
- target population
- exposure, intervention, comparator, or care context
- primary and secondary clinical outcomes
- confounders and effect modifiers
- ethics statement needs when appropriate

Default journal tone:
- generic high-quality biomedical journal
- restrained JAMA-like general medicine voice unless a target journal is named

Preferred medical outputs when applicable:
- Table 1 baseline characteristics
- patient flowchart
- primary outcome plot
- subgroup forest plot
- Kaplan-Meier curve when time-to-event analysis is used
- calibration or diagnostics plot when modeling requires it
- baseline-analysis table and figure outputs before inferential modeling
- between-group comparison outputs before adjusted modeling outputs

Medical analysis expectations:
- go beyond one-way group comparisons when the study question supports richer modeling
- prefer adjusted regression models, repeated-measures models, survival models, or subgroup interaction analyses when justified by the endpoint and design
- report effect sizes with 95% confidence intervals throughout the manuscript
- organize analysis and reporting in the order of baseline analysis, group-comparison analysis, and modeling analysis
- make the Results and Discussion sections explicitly interpret the corresponding tables and figures from each analysis layer

Medical writing constraints:
- avoid overstating causality from observational designs
- keep Discussion organized around principal findings, comparison with literature, interpretation and mechanisms, then strengths, limitations, and implications
- make the Discussion materially deeper than a brief recap of the Results
- use AMA 11th unless the target journal requires another format
- place AMA 11th citation callouts at the supporting claim locations in the body text
- keep body text black only
- keep figures black-and-white or grayscale-safe unless the user explicitly approves color
- present inserted tables in academic three-line style unless the target journal requires another format
