# Anti-Generic Consulting Guardrails

## Purpose

Prevent the skill from degrading into a generic business-deck template system.

## Forbidden Default Skeleton

Do not automatically turn an abstract topic into:

- agenda
- executive summary
- generic issue page
- generic roadmap
- generic responsibility page
- generic closing ask

Use these only when:

- the user explicitly asks for consulting, management, governance, or board-report rhetoric
- the communication context clearly requires them

## Forbidden Degradation Behaviors

Do not:

1. replace graphic reasoning with section headers
2. write titles as labels instead of claims
3. turn graphic-worthy content into bullet lists
4. fill the main content area with repeated `待用户确认`
5. let the deck lose a visual center and become only title-plus-boxes
6. treat every request as a standard corporate briefing

## Required Countermeasures

When the draft starts drifting into generic templates:

1. re-check `what_must_be_seen_first`
2. re-check `information_loss_if_text_only`
3. increase `graphic_priority` if relation or structure carries meaning
4. switch to a graphic proposition page type
5. rewrite the title as a claim, not a section label

## Title Rule

Prefer:

- claim-led title
- interpretation-led title
- visual-argument title

Avoid:

- agenda
- background
- issues
- roadmap
- organization
- next steps

unless those labels are explicitly requested.
