# Layout patterns (16:9, white base, 微软雅黑)

Use these as building blocks. Keep each slide to **1 takeaway + 2–4 modules**.

## Global grid (default)

- Canvas: 1920×1080 (conceptual)
- Safe margins: 80px (left/right/top/bottom)
- Spacing unit: 8px
- Alignment: left edges aligned; avoid “floating” blocks

## Pattern A: Left-right two-column (most common)

- Left (40–45%): takeaway title + 2–4 bullets (reasoning / key points)
- Right (55–60%): 1 main visual (chart/flow/structure) + short labels

Use when: argument + evidence / narrative + diagram.

## Pattern B: Three-card columns

- Top: takeaway title
- Body: 3 equal cards (parallel points) each: heading + 2–3 bullets

Use when: 3 drivers / 3 findings / 3 solutions.

## Pattern C: Top-bottom sections

- Top: takeaway + short context line
- Bottom: (1) visual OR (2) 2–3 blocks for evidence/implications

Use when: needs a “headline” then supporting blocks.

## Pattern D: Center visual + side notes

- Center: mechanism/relationship diagram
- Left/right: 1–2 small modules each (interpretation / implications / next steps)

Use when: explaining a complex mechanism or system.

## Pattern E: Chart + takeaway summary

- Left/top: chart with readable labels
- Right/bottom: summary module(s)
  - “Key result” (one sentence)
  - “So what” (1–2 bullets)
  - “Action” (optional, 1 bullet)

Use when: data-driven conclusion.

## Typography (default scale)

- Title: 48–56px (accent color allowed)
- Module heading: 28–32px
- Body: 24–28px
- Caption/labels: 18–20px
- Sources footer: 14–16px (still readable)

If content forces smaller than these, split slides instead of shrinking text.
