# Style System

## Purpose

Keep decks visually coherent, professionally restrained, and readable across different domains.

## Global Style Rules

1. Prioritize message hierarchy over decoration.
2. Use one consistent grid system across the deck.
3. Keep title rhythm consistent from slide to slide.
4. Keep label shapes, arrow logic, and emphasis colors consistent.
5. Limit dense slides to one dominant visual idea.
6. Use visual tension through contrast and spacing, not through random ornament.
7. Design every page around a visible center of interpretation.

## Default Tone

Use a professional default suitable for:

- scientific communication
- corporate reporting
- consulting-style analysis
- policy or strategy review
- executive training

Characteristics:

- controlled palette
- clear hierarchy
- concise language
- precise labels
- moderate contrast
- low visual noise

## Typography Rules

- Maintain no more than 4 text hierarchy levels on a page.
- Keep slide titles short and claim-oriented.
- Use subtitles only when they clarify scope or condition.
- Prefer short fragments over full paragraphs inside slide regions.
- Use sentence fragments for labels and headers; use complete sentences for key conclusions only when needed.

## Color Rules

- Use one neutral base and one or two functional accent colors.
- Assign colors semantically, not decoratively.
- Reuse the same color meaning across the deck.
- Reserve strong highlight color for one of: decision, risk, key conclusion, or emphasis.

## Spacing Rules

- Use generous outer margins before increasing element count.
- Separate zones clearly: title, main visual, explanation, conclusion, reference.
- Preserve enough whitespace around the dominant visual so it reads as the page center.

## Information Density Rules

### Low Density

Use for chapter transitions, bridge slides, or major takeaways.

### Medium Density

Use for most professional slides. Target one main visual or one structured content block plus one takeaway.

### High Density

Use only when the subject matter demands it. Control with:

- modular grouping
- shorter labels
- clear layering
- explanation outside the central graphic

## Style Variants

Allow the user to override tone. Apply the closest variant consistently.

### Academic

- restrained palette
- evidence-first framing
- visible source zone
- minimal decorative accents

### Corporate Brand

- stronger visual polish
- slightly warmer accent use
- clearer brand rhythm in headers and section dividers

### Consulting

- claim-led headlines
- structured page zoning
- emphasis on comparison, logic, and synthesis

### Teaching

- clearer scaffolding
- more progressive explanation
- slightly lower density

### Product

- benefit-oriented wording
- cleaner feature grouping
- stronger visual anchors

### Investor Or Policy

- conservative tone
- signal-to-noise discipline
- explicit implication and action framing

## Text Rules

- Write titles to state what the slide proves or shows.
- Write titles as claims or visible propositions, not as generic section names.
- Keep explanatory text outside graphics unless it is a short label.
- Use conclusion boxes for the one message the audience should carry forward.
- Avoid filler language, vague claims, and decorative adjectives.

## Anti-Pattern List

Avoid:

- every slide using a different style
- gradients or effects without narrative purpose
- full-sentence paragraphs inside nodes
- unexplained colors
- multiple competing focal points
- oversized diagram labels that behave like body text
- agenda-heavy decks that crowd out graphic reasoning
- title-plus-bullet pages where a diagram should carry the message
