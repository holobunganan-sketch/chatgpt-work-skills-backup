## 1. 使用目的

在主线与证据之间建立可反复校正的工作关系。主线提供证据进入正文的理由，证据可以补足或改善主线。是否调整主线取决于全文流畅度、严谨性和结构收益。

避免两类偏差：

- 先写完整结论，再寻找能够贴在结论后的材料；
- 先排列现有材料，再从材料中寻找一个宽泛主题。

先建立短小、可修改的主线骨架，再让主线和材料共同决定最终段落。

## 2. 建立可修订主线

### 2.1 写出核心问题

把写作任务改写成读者能够回答的问题。使用具体对象和判断，避免“全面讨论”“系统分析”等宽泛任务。

### 2.2 写出目标答案

用一至三句话记录全文拟交付的答案。保留修订空间，不提前完成修辞。

### 2.3 标出必要节点

根据文类选择合适结构：

- 问题 → 现象 → 原因 → 结果 → 含义；
- 研究发现 → 与既有研究的关系 → 解释 → 后续判断；
- 规则 → 当前事实 → 适用判断 → 行动；
- 选项 → 统一标准 → 分支比较 → 决策；
- 时间变化 → 关键节点 → 影响 → 当前状态。

删除不影响目标答案的节点。保留读者完成推理必需的节点。

## 3. 定义段落判断

为每段写一个内部判断句，回答：

- 本段结束时，读者应当接受什么？
- 这个判断怎样推动全文？

内部判断句需要包含具体主体和关系。示例：

- 含混：该因素具有重要作用。
- 具体：用药依从性下降使持续治疗时间缩短，并增加了随访中断。

段落可以包含多项材料。所有材料共同完成一个主要判断。

## 4. 识别推理缺口

比较相邻节点，寻找读者无法自行补足的关系：

- 现象已经出现，原因尚未解释；
- 结果已经报告，与当前问题的关系尚未建立；
- 两组证据已经列出，共同点或差异尚未说明；
- 研究发现已经陈述，后续判断缺少连接；
- 建议已经提出，前文尚未建立必要理由。

把推理缺口写成具体问题：

- 哪项观察能够说明该结果持续存在？
- 哪个比较能够解释两组结果的差异？
- 哪项研究能够连接症状变化与治疗行为？
- 哪个已知关系能够把本研究发现推进到临床判断？

## 5. 分配证据任务

证据任务描述证据在当前推理中的动作。优先使用下列任务：

- 建立现象；
- 量化规模；
- 解释原因；
- 比较一致性；
- 说明差异；
- 补足中间关系；
- 区分解释；
- 连接研究发现与当前问题；
- 支持后续判断；
- 提供具体例证。

为每项证据记录：

| 字段 | 内容 |
|---|---|
| 进入点 | 它接续哪个既有判断 |
| 推理缺口 | 它帮助解决什么问题 |
| 证据任务 | 它完成什么动作 |
| 本文判断 | 作者使用该证据后推进到什么 |
| 后续去向 | 下一句或下一段继续什么 |

“说明该问题很重要”“丰富了讨论”“提供了参考”缺少具体论证动作，需要继续改写。

## 6. 决定是否调整主线

### 6.1 保持主线

遇到下列情形时保持主线：

- 证据能够直接完成现有推理缺口；
- 证据只增加量化或具体例证；
- 现有段落顺序已经符合读者推理；
- 调整会增加旁支或重复；
- 调整只为容纳一项来源。

### 6.2 局部调整

遇到下列情形时评估局部调整：

- 证据揭示两个节点之间缺少必要解释；
- 原段落把两个主要判断混在一起；
- 原顺序先给出结论，后文才提供必要依据；
- 多项证据形成新的比较关系；
- 一个宽泛节点可以拆成两个连续的具体判断；
- 调整能够减少引用突兀和语言绕行。

### 6.3 比较两种方案

分别写出：

1. 保持原主线后的段落推进；
2. 局部调整后的段落推进。

选择以下表现更好的方案：

- 读者需要补足的推理更少；
- 证据目的更清楚；
- 段落任务更集中；
- 语言更具体；
- 相邻段落更自然；
- 全文更紧凑。

主线调整无需成为每项证据的固定结果。

## 7. 组织多项证据

### 7.1 共同完成一个任务

多项证据承担相同任务时，先写共同结论，再用必要来源提供数据或差异。把来源整合到同一句或围绕同一主体的句群中。删除连续的作者主导句。

### 7.2 分别完成不同任务

按照读者需要的推理顺序排列。例如：

`建立现象 → 量化规模 → 解释原因 → 推进到当前判断`

### 7.3 形成比较

明确比较对象、相同点、差异点和差异对当前判断的影响。研究名称和发表顺序不构成比较。

### 7.4 来源本身属于分析对象

当任务需要比较研究设计、政策文本、法律规范或历史观点时，可以保留逐项来源结构。每项来源仍需服务统一比较标准。

## 8. 重编译段落

按以下顺序工作：

1. 写出段落判断；
2. 写出进入点和离开点；
3. 排列证据任务；
4. 构建推理桥；
5. 决定句子合并与拆分；
6. 对齐主体、术语、语气和节奏；
7. 删除无推进作用的材料。

证据句已经完成当前推理时，检查后续解释是否产生新判断。同义复述不构成作者推进。

检查段落是否提前给出证据将要导出的判断。出现“判断—证据重复—同义总结”时，把段落压缩为“已知问题或发现—证据贡献—本文推进”。

允许大幅调整原句。保留原文中已经准确、自然并承担有效任务的部分。

## 9. 双向审计

### 9.1 从主线到证据

沿核心问题、段落判断和目标答案检查：

- 每个必要节点是否已经建立；
- 每项需要证据的关系是否有材料完成；
- 是否存在结论提前出现；
- 是否存在材料堆积而判断缺失。

### 9.2 从证据到主线

从每项引用返回：

- 它服务哪个段落判断；
- 它填补哪个推理缺口；
- 它使本文能够继续说什么；
- 它的位置是否自然。

### 9.3 压力测试

- 隐藏引用标识，检查段落是否仍能显示证据任务。
- 删除证据内容，检查哪一步推理中断。
- 调换证据句顺序，检查推理是否受损。
- 用另一篇主题相关来源替换当前来源，检查论证是否失去具体性。
- 用一句话概括段落，检查材料是否共同完成该判断。

## 10. 完成标准

- 主线骨架保持可解释，局部调整具有全文收益。
- 每段完成一个主要判断。
- 每项证据具有进入点、任务、本文判断和后续去向。
- 证据顺序服从推理顺序。
- 读者无需了解检索过程或反馈背景。
- 删除材料后能够指出具体损失。
- 全文没有为容纳材料而产生的旁支。
