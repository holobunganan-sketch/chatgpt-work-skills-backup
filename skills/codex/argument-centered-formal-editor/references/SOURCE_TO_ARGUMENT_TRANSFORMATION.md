## 1. 使用目的

根据来源叙事与本文当前任务的契合程度，选择保留、轻调、提取或舍弃。把适配程度控制在完成全文主线所需的范围内。

来源叙事包含来源自己的研究问题、对象、方法、结果顺序和解释。来源叙事可以直接服务本文，也可能只提供其中一个局部命题。

## 2. 判断来源叙事

逐项回答：

1. 来源与本文是否讨论同一问题？
2. 来源中的主体是否能够延续本文当前主体？
3. 来源结论是否承担本文当前需要的任务？
4. 来源叙述顺序是否能够自然接续上文？
5. 来源的完整背景是否影响读者理解当前判断？
6. 来源进入正文后是否会使段落变成文献摘要？

使用回答确定契合度。不要把主题相似直接判为叙事契合。

## 3. 四级适配

### 3.1 高度契合：保留

适用条件：

- 研究问题与本文当前问题一致；
- 来源结论直接完成段落任务；
- 主体和术语能够自然延续；
- 原叙述关系已经清楚。

处理：

- 保留原有逻辑关系；
- 调整必要的指代、语序和引用位置；
- 延续本文术语；
- 删除重复背景。

### 3.2 部分契合：轻调

适用条件：

- 来源提供本文需要的主要关系；
- 来源主体或表述视角与本文存在差异；
- 来源包含少量无关背景。

处理：

- 把句子主体调整为本文当前对象；
- 保留有用的因果、比较、递进或解释关系；
- 压缩方法和背景；
- 把来源结果接入本文判断。

### 3.3 局部可用：提取

适用条件：

- 来源整体研究问题与本文不同；
- 某项事实、变化关系、比较或解释能够推进本文；
- 来源完整叙事进入后会造成旁支。

处理：

- 提取最小可用命题；
- 使用本文术语重述；
- 让该命题填补具体推理缺口；
- 保留对应引用；
- 舍弃无关叙事。

### 3.4 无推进作用：舍弃

适用条件：

- 来源只有主题相关性；
- 来源不能改变、解释、量化或推进当前判断；
- 删除后没有任何推理损失；
- 来源进入后需要另设旁支才能解释其存在。

处理：

- 不写入正文；
- 必要时保留在内部材料池；
- 不为满足引用数量保留。

## 4. 提取最小可用命题

从来源中寻找具体内容：

- 谁或什么对象；
- 在何种研究或情境中；
- 出现了什么变化；
- 两个变量形成什么关系；
- 哪个比较产生什么差异；
- 哪项观察解释当前结果。

把来源完整摘要压缩为本文需要的一项事实或关系。保留能够决定句义的数字、方向、对象和术语。

内部记录：

| 项目 | 示例形式 |
|---|---|
| 来源原命题 | A组的X高于B组 |
| 本文推理缺口 | 当前差异缺少外部比较 |
| 最小可用命题 | 既有研究观察到同方向组间差异 |
| 证据任务 | 比较一致性 |
| 本文后续判断 | 当前结果延续了既有观察 |

## 5. 保留来源叙事

来源与本文高度契合时，优先保留有效叙事。检查：

- 是否已经使用本文当前主体；
- 是否已经完成所需推理；
- 是否存在术语差异；
- 是否重复前文；
- 引用位置是否清楚。

完成必要调整后停止。保留自然契合的句子能够维护作者声音和段落节奏。

## 6. 调整来源叙事

### 6.1 调整主体

来源摘要常以作者或研究为主体：

> 某研究发现，患者的随访频率与依从性相关。

本文正在讨论依从性时，可以改为：

> 随访频率与依从性的同步变化已在既有研究中得到观察。

根据上下文继续具体化该关系。作者姓名和研究名称只在比较研究本身时承担句子主体。

### 6.2 调整信息顺序

把读者当前已知内容放在句首，把新增信息放在句末。利用旧信息接续上文，利用新信息推动下文。

### 6.3 调整术语

选择全文已经建立的术语。来源术语与本文术语具有明确对应时使用本文术语；专有名词、量表名称和受控术语保持原样。

### 6.4 调整叙述粒度

本文只需要一项关系时，压缩来源的方法背景。本文正在比较研究设计时，保留方法差异。

## 7. 形成本文判断

证据内容进入正文后，需要明确本文据此推进到什么。该判断可以由以下方式表达：

- 因果谓语；
- 比较结构；
- 归纳共同点；
- 说明差异对当前解释的影响；
- 把外部观察连接到本文发现；
- 把当前发现导向下一问题。

允许证据内容和本文判断融合在同一句中。避免固定追加“这表明”“这一证据说明”。

## 8. 引用位置

- 把引用放在其对应的具体命题之后。
- 一句包含多个不同命题时，分别判断引用位置。
- 多项来源共同完成同一任务时，可以合并引用。
- 同一来源承担不同任务时，在各自对应位置使用。
- 移动或拆句后重新检查引用位置。

## 9. 常见失败

### 9.1 逐篇摘要

信号：连续句子以作者、年份或“研究发现”开头。

处理：先写共同判断，把承担同一任务的来源整合到同一句或围绕本文主体的句群。研究差异属于当前判断时保留研究主体。

### 9.2 强制提取

信号：来源原叙事已经自然契合，改写后句子更绕、语气更生硬。

处理：恢复原有关系，只保留必要调整。

### 9.3 强制保留

信号：来源背景占据段落，本文问题暂时消失。

处理：提取最小可用命题，恢复本文主体。

### 9.4 只有主题相关性

信号：引用可以替换为任何同主题文献，段落含义基本不变。

处理：重新指定具体任务，无法指定时舍弃。

### 9.5 来源术语接管全文

信号：引证处出现新的抽象术语，后文不再使用。

处理：改用本文术语或写明该术语的具体对象和关系。

### 9.6 防御性尾句

信号：引用后保留“不能证明”“不代表”“需要谨慎解读”等句子，当前任务只要求把证据接入主线。

处理：从改写目标段落移除。用户明确要求编辑限制章节时，按照限制章节自身任务处理。

## 10. 完成检查

- [ ] 已判断来源叙事契合度。
- [ ] 处理动作与契合度一致。
- [ ] 高度契合的叙事得到保留。
- [ ] 部分契合的材料完成主体和关系调整。
- [ ] 局部可用材料只保留推动本文的命题。
- [ ] 无推进作用的材料未进入正文。
- [ ] 引证处延续本文术语和语气。
- [ ] 引用位置对应具体命题。
- [ ] 读者能够说明该来源在此处完成的任务。
