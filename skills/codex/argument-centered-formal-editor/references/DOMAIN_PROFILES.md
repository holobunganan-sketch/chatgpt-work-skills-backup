## 1. 加载原则

只读取当前文类对应部分。文类规则增加结构、术语和表达要求，继续执行主线连续、证据任务、来源适配、推理桥、具体表达和过程隔离。

来源核验、证据等级和支持范围由上游任务处理。本技能不得主动增写证据边界、限制条款和防御性说明。

## 2. 学术与研究文本

### 2.1 主线

让研究问题、研究设计、结果、解释和结论逐项对应。根据章节功能组织：

- 引言：建立研究问题和明确缺口；
- 方法：说明研究如何回答问题；
- 结果：报告与问题直接相关的观察；
- 讨论：解释主要发现，与既有研究形成具体关系；
- 结论：回答研究问题。

### 2.2 证据整合

- 让讨论段落围绕本研究的一项主要发现展开。
- 判断既有研究与当前发现属于一致、差异、解释、补充或后续推导中的哪一种关系。
- 来源叙事高度契合时保留其有效关系。
- 来源研究问题不同但局部结果有用时提取最小可用命题。
- 合并承担相同任务的来源。
- 保留研究设计差异仅限于该差异影响当前比较时。

### 2.3 具体表达

- 优先写明研究对象、样本、变量、干预、测量、比较组、时间和结果。
- 使用明确变化方向和统计指标。
- 抽象术语紧邻具体对象和关系。
- 删除“具有重要意义”“提供新视角”“丰富研究”等通用评价。
- 避免连续使用“机制、路径、维度、框架、层面”等抽象名词。
- 结果章节保持观察性表达，讨论章节承担解释。

### 2.4 语气

- 延续全文术语和时态。
- 引证处保持本文发现或当前问题为叙述中心。
- 作者姓名和研究名称只在研究差异属于当前判断时担任主体。
- 保持摘要、正文、图表和结论中的变量名称一致。

### 2.5 引文管理器兼容

- 把 Zotero 或其他引文管理器生成的 citation key、引文命令和动态域登记为受保护对象。
- 重组句段时让引文随受支持的最小陈述共同移动。
- 保留 citation key 的内容、大小写、组合关系和格式参数。
- Word 中的动态引文保持为动态域，不进行文本化处理。
- 文库检索、条目选择、引文插入、同步和样式刷新由外部引文管理流程完成。

## 3. 政策与治理文本

### 3.1 主线

按照需要连接：

`问题表现 → 影响对象 → 原因或制度环节 → 政策选择 → 实施主体 → 预期结果`

### 3.2 证据整合

- 统计数据量化问题。
- 案例说明执行表现。
- 规范文本提供制度依据。
- 利益相关方材料说明实施条件或影响。
- 各项措施对应前文已经建立的问题。

### 3.3 表达

- 写明主管主体、适用对象、权限、时间和资源。
- 统一比较政策选项的标准。
- 把执行细节集中到对应行动部分。
- 删除宣传口号和抽象治理表述。

## 4. 商业与咨询文本

### 4.1 主线

按照需要连接：

`商业问题 → 指标表现 → 原因判断 → 选择标准 → 建议 → 验证方式`

### 4.2 证据整合

- 经营指标建立现状。
- 用户材料解释行为。
- 市场数据提供比较。
- 案例说明可执行做法。
- 建议对应已经建立的原因和约束。

### 4.3 表达

- 写明决策人、决策时点、成本、资源和预期结果。
- 区分观测、原因判断和预测。
- 保持指标定义、时间窗口和比较基准一致。
- 删除“赋能、抓手、生态、协同”等无具体对象的词语。

## 5. 技术与工程文本

### 5.1 主线

按照需要连接：

`需求 → 约束 → 设计选择 → 接口或实现 → 验证 → 运维影响`

### 5.2 证据整合

- 基准测试支持性能判断。
- 故障记录支持问题诊断。
- 接口规范支持兼容性判断。
- 实验结果支持设计选择或验证结论。

### 5.3 表达

- 使用一致、可测试的规范性术语。
- 区分当前行为、目标行为和迁移行为。
- 写明前置条件、输入、输出、失败模式和恢复动作。
- 示例与正式接口保持一致。

## 6. 法律与合规文本

### 6.1 主线

按照需要连接：

`规则 → 构成条件 → 当前事实 → 适用判断 → 程序或后果`

### 6.2 材料整合

- 法源用于识别规则。
- 定义用于确定术语含义。
- 当前事实用于判断构成条件。
- 例外用于确定适用结果。

### 6.3 表达

- 保留定义术语、主体、时限、条件、否定和例外。
- 检查交叉引用、附件和优先顺序。
- 区分义务、授权、建议和事实陈述。
- 拆句时保持条件与后果对应。
- 法律效力或适用法需要确认时暂停相关实质改写。
