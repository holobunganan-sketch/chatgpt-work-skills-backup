# Scientific Specialization

Use this layer on top of the shared research core.

Scientific framing should explicitly capture:
- scientific significance
- system, material, dataset, apparatus, or process under study
- independent variables, interventions, or parameter settings
- primary endpoint, benchmark, or validation target
- nuisance variables, boundary conditions, heterogeneity, or alternative mechanisms

Default journal tone:
- generic high-quality scientific journal
- restrained and precise unless the user names a venue

Preferred scientific outputs when applicable:
- dataset or system characteristics table
- workflow or process diagram
- primary result figure
- robustness, ablation, subgroup, or heterogeneity figure when justified
- diagnostic, calibration, residual, or validation plot when applicable

Scientific analysis expectations:
- go beyond descriptive outputs when the question requires inference, comparison, prediction, or validation
- include model-based analyses, robustness checks, and diagnostics where justified
- report effect sizes, uncertainty intervals, error metrics, or validation statistics suited to the domain

Scientific writing constraints:
- avoid overstating mechanism when only associative or predictive evidence is available
- avoid shallow discussion sections that only repeat the findings
- separate empirical findings from method validation findings in methods-oriented papers
