# Rigor Levels and Manuscript Types

## Rigor Levels

### `prototype`

Aim for structure validation with lighter analytical depth while still producing a coherent, analysis-ready research package.

### `submission`

Aim for a near-submission package with full traceability, journal-aware style, deeper analysis, and a complete set of core submission files.

### `high_rigor`

Add deeper diagnostics, robustness checks, literature triangulation, reproducibility detail, explicit QC notes, and a more developed discussion section.

## Manuscript Types

### `original_article`

Default mode. Expect full IMRaD structure, primary analysis, supporting analyses, and a complete submission package.

### `brief_report`

Keep the question narrow, reduce figure and table count, and shorten the discussion while preserving traceability.

### `narrative_review`

Do not invent systematic-search rigor. Emphasize thematic evidence synthesis, structured claims, and explicit source support.

### `systematic_style_overview`

Use when the user wants structured evidence mapping without claiming a full systematic review unless the underlying process supports that standard.

### `methods_paper`

Center the contribution on methods, validation logic, diagnostics, reproducibility assets, and boundary conditions rather than purely substantive findings.
