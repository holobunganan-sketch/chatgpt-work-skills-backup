# Language and Integrity

## Language Rules

- Accept user instructions in Chinese or English.
- Distinguish the working language from `OUTPUT_LANGUAGE`.
- Default `OUTPUT_LANGUAGE` to English.
- Switch the manuscript and submission assets to Chinese only when the user explicitly requests Chinese.
- If the user requests bilingual output, produce one primary manuscript language and label the second-language files as adapted versions.
- State the chosen `OUTPUT_LANGUAGE` near the top of `project_plan.md` and `submission/file_manifest.md`.

## Internal Consistency

- Keep the research question, design, variables, code, results, tables, figures, and claims aligned.
- Do not draft conclusions first and retrofit analyses later.
- Do not let prose outrun the evidence.
- Do not insert workflow labels, demo labels, or meta-commentary into the manuscript title or abstract unless the user explicitly requests a methods demonstration paper.

## Traceability

- Ensure every reported result can be traced to the working analysis dataset, analysis code, and locked result artifacts.
- Keep `results/results_summary.json` as the single locked source for quantitative manuscript claims.
- Once a working analysis dataset has been established in the workflow, analyze it fully and use it consistently throughout the manuscript and submission package.
- When no dataset is provided, generate one and proceed without treating the absence of user-supplied data as a blocker.

## Research Integrity

Do not fabricate:
- literature
- authors
- journals
- DOI values
- standards
- guidelines
- sample characteristics
- effect estimates
- model outputs

If support is missing in the literature or reporting standard layer, mark it explicitly. Keep the dataset, analyses, and manuscript mutually consistent and submission-grade in form. Focus on delivering a complete, analysis-backed manuscript rather than pausing on how the dataset was obtained.

## Writing Style

Default style:
- restrained
- precise
- publication-grade
- not promotional
- not conversational
- not student-like
- black text only in the manuscript body
- no decorative font colors
- visual outputs should remain grayscale-safe unless color is explicitly authorized

Write with clear section subheadings and developed academic paragraphs. Prefer fewer, fuller paragraphs over many short fragments.

Avoid these phrases in manuscript prose:
- `In summary`
- `It is worth noting that`
- `This clearly proves`
- `groundbreaking`
- `revolutionary`
- `simple summary`
- `key takeaway`
- `obviously`
- `undoubtedly`
